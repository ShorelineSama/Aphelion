关于 Open Aphelion

Aphelion：天体轨道上离太阳最远的一点。

Open Aphelion 是 ShorelineSama 的独立软件工作室。这一页讲清楚三件事：名字从哪来、规则是什么、谁在做。

A· 命名宇宙 / NAMING

从物理与天文里取名。

Distortion 取自信号与时空的畸变——音频的失真，也是引力透镜的偏折；Aphelion 是轨道上离太阳最远的一点；YoursGit 把版本控制的主语还给「你」。三个名字共享同一套隐喻系统：物理与天文。我们不解释热爱，只命名它。

字标里的图形同样是推导出来的：Aphelion 的 o 被替换成一条倾斜的椭圆轨道——开普勒第一定律说轨道是椭圆、太阳居焦点；环上的橙点即远日点，整颗天体离太阳最远的时刻。首字母 O 保持圆形：轨道的理想形状本就该是个圆。

B· 工程原则 / PRINCIPLES

四条原则，全部有代码背书。

P·1

本地优先

三件作品都能在断网环境完成全部核心功能。Distortion 的曲库、IdP 的账号库、YoursGit 的解析目标，全在用户磁盘上。

P·2

克制依赖

IdP 运行时零依赖；本站同样零框架零构建。依赖每少一个，供应链就少一分风险，分发就轻一分。

P·3

测试先行

2600+ 用例守着播放器内核，17 个端到端用例守着身份服务，图布局与解析器各有单测。测试不撒谎。

P·4

克制的动效

rise ≤ 300ms，hover ≤ 240ms，尊重 prefers-reduced-motion。动效服务于层级，不服务于炫技。

C· 团队 / CREW

一个人，一条产品线。

ShorelineSama

FOUNDER · 独立开发者

从视觉系统、音频内核到身份协议，一个人承担设计、工程与审美决策。白天写 WASAPI 独占输出，晚上修 git 对象库；事故有记录，测试不撒谎。核心作品以 AGPL-3.0 回馈开源社区。

D· COLOPHON

本页如何建成。

技术

静态 HTML / CSS / JS · 零框架 · 零构建 · 零第三方运行时依赖。

演示动画为 CSS 状态类 + JS 时间轴编排，可重播。

双语
