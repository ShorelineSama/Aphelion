轨道日志

全部日期取自仓库、文档与测试日志；不编造，不美化。

「只做可逆操作；任何删除或从版本库移除的动作都需要明确确认，逐条列出。」 —— docs/project-layout.md · 仓库整理原则
  1. 2026 · 秋
    Distortion 立项

    本地 Hi-Fi 无损播放器开始发育：多引擎音频内核、本地曲库、封面与歌词。早期提交历史后来灭失，确切起点成了谜——我们不编造它。

  2. 2026-09-05
    520 项功能共识清单落盘

    grilling 式设计拷问的产物：F001–F520，覆盖播放核心、音质 DSP、曲库元数据、歌词、生态接入等十二个方向，成为全页面重写与 Three.js 沉浸化改造的功能池。

  3. 2026-09-17
    git 历史灭失，当日重建

    .git 对象库损坏，全部历史灭失。当日重建仓库基线，从第 1 个提交重新开始——automix 位点补记、拍点网格回退路径那批 fix 提交成了新的创世记录。

  4. 2026-10-18
    第一、二轮仓库整理

    日志、编译缓存、探针截图归档；17 个 Blender/GLB 脚本归入 scripts/blender；typecheck 双查 exit 0。全程未删除任何文件。

  5. 2026-10-29
    第三轮：误入库的 7.8 GB 出清

    extensions/.build 里 1430 个跟踪文件（Chromium 用户配置与探针）移出版本库，磁盘原样保留；跟踪文件 2427 → 997；2667 项测试与 build 全绿。

  6. 2026-10
    Aphelion IdP 发布

    OAuth2 授权码 + PKCE / OIDC 身份中枢上线：零第三方依赖，Tauri 86 MB 单包分发，端到端验证 17/17；内置平台与桌面双客户端，审计留痕 2000 条。

  7. 2026-10-31
    第 496 个提交落下

    一句话生成歌单（本地语义解析 + 结果预览）、歌词编辑器、相似电台、心情标签、重复合并与互联同步组件；windows-smtc 兼容两套 Windows SDK。YoursGit v0.1.0 早期预览同步在轨调整。

  8. 2026-10-31
    本站上线

    多页站点 + 中英双语 + 开普勒方程驱动的轨道演示动画。零框架、零构建、零第三方运行时依赖——与 Aphelion IdP 同一哲学。
