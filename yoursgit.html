WORK 03· v0.1.0 · EARLY PREVIEW

YoursGit

提交星图 · 本地 Git 提交可视化桌面应用

把仓库的提交历史画出来。分支图布局引擎是自研的、有单测的；热力图、统计与时间线各占一个面板。数据完全在本地解析——一条 git log 都不会离开你的磁盘。名字里的主语是「你」：这是你的 Git。

v0.1.0 Windows · Electron 31 React 18 · Vite 5 全本地 · 零上传

A· 五个面板 / PANELS

历史不止一种看法。

提交分支图

  • 自研图布局引擎：分支线着色与合并走向
  • 布局算法独立单元测试（graphLayout.test）
  • 点选任意提交联动详情面板

贡献热力图

  • 按日聚合的提交强度视图
  • 统计计算独立模块（stats.ts）+ 单测
  • 与时间线联动定位密集期

统计与时间线

  • 仓库总量、作者与频率分布
  • 时间线面板纵览里程碑
  • 格式化工具独立模块（format.ts）

提交详情

  • 哈希、作者、时间与完整说明
  • 大文本虚拟滚动不卡顿
  • mock 数据模式随时演示

B· 工程注记 / ENGINEERING

可视化是表层，解析才是内核。

本地解析

  • gitApi 直读本地仓库，无守护进程、无上传
  • 解析器单测（parse.test）覆盖边界输入
  • Electron 主进程承担 IO，渲染层只画图

性能

  • 万级提交虚拟滚动（useVirtual）
  • 图布局增量计算，滚动不掉帧
  • vitest 全量跑测试一条命令

C· 路线状态 / STATUS

v0.1.0，说实话的阶段。

YoursGit 处于早期预览：核心面板与解析管线可用，安装包为开发构建（electron-builder dist）。它排在 Distortion 与 Aphelion IdP 之后的轨道上，路线以提交历史为准——不画大饼，提交说话。
