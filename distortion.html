WORK 01· v1.0 · STABLE

Distortion

失真 · Aurorether Music NEXT · 本地 Hi-Fi 无损音乐播放器

以本地曲库为中心的无损播放器：你的 FLAC、你的 DSD、你的封面与歌词，全部留在你的磁盘上。音频内核追求位完美路径，视觉层追求逐字逐帧的沉浸，扩展系统把剩下的可能性交给社区。

Windows NSIS Android APK AGPL-3.0 Electron 43 · React 19 ONNX Runtime 2667 tests

A· 能力全景 / CAPABILITIES

八个方向，一条内核。

播放核心

  • 四模式播放 · 0.75–2.0 变速 · 变速不变调
  • A-B 段落循环 · 章节跳转 · 跳过片头片尾
  • 队列与来源分离 · 下一首插队
  • 崩溃快照恢复 · 播放位置记忆

音质 · DSP

  • 多音频引擎自动协商（HTML5 / 原生）
  • WASAPI 独占 · DSD DoP 直通 · 位完美路径
  • 10 段 EQ · ReplayGain · 响度标准化 LUFS
  • 空间音频 HRTF · 动态响度压缩（夜间模式）

曲库与元数据

  • 文件夹扫描 · mtime 增量 · 监视实时变更
  • 重复检测（标题+时长+指纹）· 批量编辑器
  • 智能播放列表规则引擎 · 评分与爱心双体系
  • GBK / Shift-JIS 标签乱码修复

歌词系统

  • Apple Music 风格逐字歌词（@applemusic-like-lyrics）
  • TTML 支持 · 歌词编辑器
  • 桌面歌词 · 歌词可视化插件位
  • Three.js 沉浸化层

生态与投屏

  • DLNA 投屏（dlnacasts）· MJPEG 屏幕投射
  • 蓝牙输出路由 · SMTC 系统媒体控制
  • B 站视频与合集导入（可选 MV）
  • WebDAV / NAS · 流媒体曲源接入

智能

  • ONNX beat_this 节拍检测 · 自相关 DSP
  • 自动混音引擎 · song-links 引擎
  • 一句话生成歌单（本地语义解析）
  • 本地大模型（node-llama-cpp）

效率

  • 19 个全局快捷键
  • Run 风格 Ctrl+K 命令终端
  • 外观实验室 50+ 项设置
  • 曲库工具与互联设置分区

移动端

  • Capacitor 8 Android 壳工程
  • APK 构建管线（build:apk / build:all）
  • 与桌面端共享渲染层
  • 离线优先的曲库同步

B· 插件系统 / EXTENSIONS

可能性交给社区，权限写进清单。

机制

  • ZIP 扩展包 · manifest.json 清单 · apiVersion 协商
  • 宿主 esbuild 管线即时编译 TS/TSX 源码
  • 三类扩展：lyrics-visualizer / runtime-provider / appearance
  • permissions 显式声明 · 路径穿越与软链拦截

分发

  • 自包含打包：node_modules 随 ZIP 分发，目标机可离线
  • npm run pack:ext 一条命令出包
  • react/zustand 等走宿主实例，避免双份
  • UI 开关：hideTitleBar / hideConfigPanel 等五项
「扩展包完全自包含，运行时由宿主 esbuild 管线从源码即时编译。」 —— EXTENSIONS.md · Distortion 扩展标准

C· 视觉系统 / VISUAL SYSTEM

夜色编辑。

Distortion 的界面建立在一套自建的视觉语言上：近黑底色的五档表面阶梯（不用阴影也能读出层次）、眉标+大标题+副标题的三级编辑化排版、随当前封面动态推导的主色（OKLCH 钳位明度保证对比度），以及克制的动效纪律——rise ≤ 300ms，hover 抬升 ≤ 240ms，尊重 prefers-reduced-motion。

「编辑化的本质是层级，不是装饰。」 ——《视觉系统 · 夜色编辑》

D· 获取 / GET IT

两个安装包，一条许可。

Windows

NSIS 安装包（electron-builder），含 FFmpeg 与 windows-smtc 原生模块，支持 SMTC 与 WASAPI 独占输出。

npm run build:exe

Android

Capacitor 8 壳工程打包 APK，与桌面端共享渲染层；离线曲库优先。

npm run build:apk
